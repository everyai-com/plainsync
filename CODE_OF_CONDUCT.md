# PlainSync Code of Conduct

PlainSync is built by people with different backgrounds, experience levels, identities, and communication styles. We want participation to be safe, constructive, and welcoming.

## Expected behavior

- Be respectful, patient, and specific.
- Critique ideas and code without attacking people.
- Assume good intent while remaining open to correction.
- Welcome questions and explain unfamiliar project conventions.
- Credit other people's work and respect privacy.
- Accept maintainer decisions gracefully, including requests to narrow scope.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks
- Sexualized language or unwanted attention
- Publishing private information without permission
- Deliberate disruption, spam, or sustained bad-faith argument
- Retaliation against someone who reports a concern

## Reporting and enforcement

For ordinary project disagreements, pause and ask a maintainer to help. Report harassment or sensitive conduct issues privately to the maintainers rather than opening a public issue. Repository owners may remove content, limit participation, or ban an account when necessary to protect the community.

Enforcement decisions should consider context, impact, prior behavior, and opportunities for repair. Good-faith mistakes should normally begin with a clear explanation and a chance to improve.

This code applies in repository issues, pull requests, discussions, and other spaces officially representing PlainSync.
